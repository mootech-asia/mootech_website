# 熊北 生成提示詞

每次生成都要上傳三視圖（或任一張定稿圖）當參考圖，並在提示詞最前面貼上「共同設定」。

## 共同設定（每張都先貼這段）
```
以參考圖的北極熊「熊北」為準，角色造型必須完全一致：高大圓潤可愛的北極熊，蓬鬆細緻的白色毛髮，戴橘到洋紅到紫藍漸層的科技感太陽眼鏡（鏡片上有 HUD 圖形），頭戴有青藍與橘色發光圓環的耳機，左側有細長麥克風臂；穿深海軍藍色一格一格鼓起的泡泡背心，左胸使用官方藍綠至黃綠漸層「不可能 M」圖形＋白色 MOOTECH 字標（參考官方原檔，不採用舊圖的變形標誌），內搭深灰色連帽衣。高擬真 3D 角色渲染、C4D 質感、柔和攝影棚光。不要國旗、其他標誌或任何多餘文字。
```

## 三視圖
```
（共同設定）製作一張專業的 3D 角色設定三視圖，16:9，純淺灰色平塗背景，由左到右並排正面、側面、背面三個全身站姿，同樣大小、腳底對齊，標準 A 字站姿，三個視角的造型、比例、配色完全一致。同一個角色的三個角度，不是三個不同的角色。背面背心上沒有任何標誌或文字。
```

## 全身姿勢（直式 1024×1536，透明背景 PNG）
在共同設定後面加上「透明背景 PNG，角色完整、四周留白」，再接一種姿勢：
- 介紹：`側身站立，一隻熊掌朝畫面右側攤開，像在介紹旁邊的內容，另一隻熊掌插腰，自信微笑。`
- 守護：`雙手在胸前撐著一面半透明的青藍色發光六角形防護盾，神情堅定可靠。`
- 托地球：`單手托著一顆無重力漂浮的發光地球，地球上有新加坡、台灣、香港、東京之間的發光連線，抬頭看著地球微笑。`
- 比讚：`面向鏡頭比出大大的讚，另一隻熊掌拿著半透明全像平板，開心大笑。`
- 打招呼：`一手扶著耳機麥克風像在接聽，另一手朝鏡頭揮手，旁邊漂浮一個發光信封圖示。`

## 表情貼圖（正方形 1024×1024，透明背景 PNG）
在共同設定後面加上「胸像構圖，角色佔畫面八成，臉部清楚，表情誇張一點方便縮小後辨識」，再接一種表情：
打招呼揮手／摸下巴思考／比讚眨眼／雙手拿著發光履歷／伸出熊掌握手／雙手在胸前比愛心。

> 注意：要寫「角色佔畫面八成」，否則容易生成很小的角色、四周大片空白。

## 局部特寫（網站點綴用，依版面裁切）
```
（共同設定）只呈現熊北從畫面右側邊緣探出半顆頭與一隻熊掌，像在偷看左邊的內容，透明背景 PNG，角色其他部分在畫面外。
```

## 招聘主視覺影片（即夢，圖生影片，15 秒）
定稿圖：熊北托著地球、左側為「WE NEED YOU / JOIN MOOTECH / NETWORK ENGINEERS / SINGAPORE · TAIPEI / NOW HIRING」組合文字。
重點指令（完整版見專案對話紀錄）：
- 首尾畫面一致可無縫循環；所有英文文字固定、拼字不變
- 文字逐行滑出再帶殘影飛回；NOW HIRING 強烈爆閃兩次（每次三下）
- 周圍全像監控面板環繞旋轉、收合再新增，只出現綠色打勾，完全不出現紅色警示
- 墨鏡與耳機 LED 全程點亮
- 約 10.5～13.5 秒熊北前傾、熊掌伸出螢幕直指觀眾（「我就是要你」），帶螢幕邊框破框效果

### 新版：打破螢幕玻璃＋「來吧！」（2026/11/10）
定稿圖：熊北在右側托著漂浮地球，左側為同一組文字。在上面的重點之外再加上：
- 0.8～3.5 秒文字由上到下依序從左外側彈入，每組間隔約 0.45 秒，落定時閃白光
- 6.5～8.5 秒畫面浮現玻璃螢幕並出現蜘蛛網狀裂紋；8.5 秒熊掌擊穿玻璃，碎片帶青藍光邊朝鏡頭飛散
- 8.5～11 秒熊掌突出畫框直指觀眾；11～13.5 秒勾手做兩次「來吧！」，可愛又自信的笑容
- 13.5～15 秒碎片倒轉飛回、裂痕癒合，回到第一格
- 環繞面板有開有關：舊面板收合成光線消失、新面板從光點展開，隨時約 5～7 個，每個面板有各自的動態（折線、儀表、拓撲、地圖光弧、長條、雷達、清單打勾、進度條），呈現忙碌但從容

1536×1024，深藍背景。版面與 Moo Rabbit 設定圖一致：Character Profile、Color Palette、五視圖、六表情、六細節與 Scale。全部標註使用英文。

Profile: Name: Mootech Bear / Style: Chibi-realistic 3D / Proportion: 1:3 / Personality: Nimble / Attentive / Energetic / Friendly / Usage: Digital mascot.

Views: FRONT / 3/4 VIEW / SIDE / BACK / 3/4 REAR.
Expressions: SMILE / LAUGH / FOCUSED / LISTENING / THINKING / THUMBS UP.
Details: HUD GLASSES / HEADPHONES / EMBROIDERED LOGO / ZIPPER / FUR TEXTURE / PAW PAD.

保留熊北的小圓耳、黑鼻、深色熊掌肉墊與 200 cm 身高；兔比 150 cm（耳朵另計）及成人 175 cm 作比例對照。頁首、胸前與標誌特寫均依官方 logo；背面無標誌。
