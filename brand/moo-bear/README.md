# 熊北｜MOOTECH 吉祥物形象資料夾

熊北是 MOOTECH 的品牌吉祥物：一隻高大圓潤、戴科技墨鏡與發光耳機的北極熊。
牠的形象代表「厚實可靠、全天候守護」，用來傳達 MOOTECH 網路服務的安全與穩定。

## 網站使用原則

1. **少量、有目的**：一個頁面最多 2～3 處出現熊北（不含右下角客服），避免看膩。
2. **以整體版面為主**：不一定是全身或半身；可以只露出局部（探頭、一隻熊掌、側臉）、裁切特寫，或縮小成區塊角落的點綴，依版面留白與閱讀動線決定。
3. **不擋內容**：熊北不可蓋住標題、內文、按鈕；手機版優先縮小或省略。
4. **動態要輕**：浮動、眨眼、輕微晃動即可；大動作只用在首屏影片與客服來電。
5. **一致性**：配件（墨鏡、耳機、背心與標誌）不可缺少或換色；生成新圖時一律附上三視圖當參考。
