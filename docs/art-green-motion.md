# 漸層形象人動畫交付

使用者選定 SRCIMG007 的無五官圓潤人物，保留原圖造型與青藍 #22B5D6 → 薄荷 #62C5AE → 黃綠 #ACD65E 漸層。七個情境各自輸出一張獨立 PNG 與一支 GIF，不再裁切角色拼圖。

| 情境 | 動作／輔助道具 | GIF／獨立 PNG |
|---|---|---|
| 願景 | 伸手與星星 | IMG119／IMG120 |
| 團隊 | 招呼、連結符號 | IMG121／IMG122 |
| 分享 | 舉手與燈泡 | IMG123／IMG124 |
| 學習 | 手部操作與筆電 | IMG125／IMG126 |
| 辦公 | 步伐擺動與窗景 | IMG127／IMG128 |
| 聚餐 | 舉杯 | IMG129／IMG130 |
| 運動 | 手臂屈伸與啞鈴 | IMG131／IMG132 |

每檔 320×320、40 幀／2 秒、每幀 50ms（20 fps）、透明背景、無限循環。動畫使用連續網格骨架變形，每個相鄰幀及循環接點均改變姿勢；往返動作可重訪相同姿勢，並非重複四個關鍵幀增加幀數。手臂、頭部、步伐與道具使用週期函數，循環端點一致。以 PNG 提供靜態獨立輸出及減少動態效果偏好。

重製：安裝 Python Playwright／Chromium 與 ImageMagick 7，執行 `python3 tools/build-green-gifs.py`，由工具自建本機 HTTP server，以 `tools/gradient-motion.html` 逐幀渲染，再編碼 GIF。SRCIMG006 為前版歷史來源，正式素材已改引用 SRCIMG007。

客服維持無吉祥物，使用中性耳機圖示。音樂、音效、影片、3D 模型、字型不適用。
