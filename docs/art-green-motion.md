# MOOTECH 修長形象人情境圖

現行網站的願景與六張文化卡，已依 SRCIMG015 中性偏男性設計稿全部重新繪製。人物採小頭身、較寬肩、平直腰胯、修長四肢、無五官與平滑一體的肢體；保留青藍→薄荷→黃綠品牌漸層及光滑反光材質。

每張分別繪製，使用各自的角度、身體姿勢與道具互動，不套用同一張站姿圖。正式交付均為 640×640 透明 PNG，單幀靜態。角色卡顯示區 176×164，願景區上限 360×280；窄螢幕以 max-width 保持在卡片內。

原稿與製作清單見 [修長形象人系列](art/slender-character-series.md)。`python3 tools/prepare-slender-scenes.py` 可由七張原稿重製正式輸出：等比例縮至 608×608 範圍，再置於 640×640 透明畫布，不變形人物。原稿與製作工具不加入網站發布包。

先前大頭角色、舊 GIF 與製作器保留原路徑供歷史相容；目前七個人物槽位只引用 IMG134–140。E 版北極熊維持原設計，客服仍依 A–E 各版型配色；已移除的三個合作夥伴不恢復。
