# E 版首屏影片

首屏是兩張輪播：

| 張 | 檔案 | 內容 |
|---|---|---|
| 1 | `e-hero.mp4`／`.webm`、`e-hero-poster-*.webp` | 黑曜石盾（原檔歸檔在 `archive/影片原檔/`） |
| 2 | `e-hero-2.mp4`／`.webm`、`e-hero-2-poster-*.webp` | 熊北招聘影片（裸眼 3D 破窗版，品牌資料夾 `04_主視覺與影片/` 也有一份） |

## 換影片（自動做成無縫循環）

```bash
python3 tools/make-loop.py 即夢下載的影片.mp4 --name e-hero-2 --fade 0.8
```

工具會把影片結尾與開頭交叉淡化，並輸出壓縮好的 mp4、webm 和對齊第一格的靜態圖。即夢下載的 60fps 影片先轉成 30fps 再做，檔案會小一半。
換完後把 `index.html` 裡該影片網址的 `?v=` 數字加 1（讓瀏覽器重新下載），並把輪播的 `DURS` 改成新的循環長度（毫秒）。

系統開啟「減少動態」時只顯示靜態圖。
