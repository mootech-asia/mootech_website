# 歸檔

網站目前沒有使用、但值得保留的原始檔。這個資料夾不會發布到網站。

| 資料夾 | 內容 | 來源 |
|---|---|---|
| `照片原檔/a`、`b`、`c/` | A、B、C 版型早期使用的照片原檔（解決方案、關於我們、服務場景、行動呼籲等），版型改用程式繪製插畫後已不使用 | 原本放在 `assets/photos-src/` |
| `影片原檔/` | E 版首屏第 1 張「黑曜石盾」影片的原始檔與首格 | 原本放在 `assets/photos-src/` |

要再用某張照片時：把 JPG 放回 `assets/photos-src/<a|b|c>/`，執行 `python3 tools/optimize-images.py` 產生 WebP。
